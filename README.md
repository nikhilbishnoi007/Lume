# Lume 📸

A full-stack social photo-sharing app where people can share moments and connect with each other.

## 🌟 About

Lume lets users upload photos with captions and tags, explore a feed of posts from others, and manage their profile — all wrapped in a clean, modern UI.

## 🛠️ Tech Stack

**Frontend**
- Next.js (App Router)
- Design system: white cards with rounded corners & soft shadows, blue primary actions, purple accents, zinc neutrals

**Backend**
- Express.js
- MongoDB
- Cloudinary (image storage)
- JWT authentication with refresh token rotation

## ✨ Features

- Secure signup/login with OTP verification
- JWT-based auth with refresh token rotation
- Upload photos with captions and tags
- Explore feed with randomized post sampling
- User profiles with post management (including delete)
- Toast notifications & confirm dialogs via context-based UI provider
- Privacy Policy & Terms pages
- Fully responsive design

## 📄 Pages

- Home
- Login / Signup / Signin
- OTP Verification
- Create Post
- Explore Feed
- Profile

- 404

## 🧠 What I Learned

Building Lume pushed me deeper into full-stack architecture — from designing JWT refresh token flows to debugging tricky issues like React StrictMode double-invocation, CORS credential mismatches, and Next.js Image quirks. It's also becoming the base for a system design case study covering load testing, caching, indexing, and rate limiting.
